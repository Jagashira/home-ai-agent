Privacy Policy

Last updated: October 4, 2026

Purpose

Home Mail Agent uses authorized Google Gmail data solely to provide personal email organization and classification functionality.

Google data accessed

The application may access:

  • Gmail message metadata
  • Sender
  • Subject
  • Received date and time
  • Message body text
  • Gmail message and thread identifiers
  • Gmail labels

The application does not intentionally process attachment contents in the current implementation.

How Google data is used

Google user data is used to:

  • Classify email
  • Determine importance and action requirements
  • Detect deadlines and events
  • Generate short summaries
  • Assign organizational Gmail labels
  • Generate daily mail digests

AI processing and DeepSeek

For email classification, selected email data is sent to the configured DeepSeek API. The data sent may include the received date and time, sender, subject, and normalized email body.

Raw attachments are not sent by the current implementation. DeepSeek is used only to provide the classification functionality described in this policy.

Local storage

The application's local SQLite database may store:

  • Message and thread identifiers
  • Sender and subject
  • Received date and time
  • Content hash
  • Classification result
  • Model and classifier version metadata
  • Classification timestamp

The application does not intentionally store the full raw or normalized email body in its classification database. OAuth credentials and API keys are stored separately from this public website and are not included in GitHub Pages.

Gmail modifications

Current Gmail modifications are limited to adding organizational labels. The application does not currently:

  • Send email automatically
  • Permanently delete email
  • Move email to Trash
  • Archive email automatically
  • Mark email read or unread automatically

Sharing, sale, and advertising

Home Mail Agent does not sell Google user data and does not use Gmail data for advertising. Third-party processing by the configured AI API is used only for classification functionality.

Security

Reasonable local measures are used to reduce unnecessary exposure of sensitive data. API keys and OAuth credentials are excluded from the public repository, OAuth tokens are stored separately, and the classification database does not intentionally store full email bodies. No system can guarantee absolute security.

Revoking access

A user may revoke the application's access to a Google account at any time through the Google Account security or third-party access settings. Revoking access prevents the application from making further authorized Gmail requests for that account.
